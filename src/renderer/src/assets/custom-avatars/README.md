# Custom avatar assets

This directory is the handoff point for a future custom team roster.

- `source/` is for temporary personal photo references. Its contents are Git-ignored.
- `roster.example.json` is a neutral, editable starting point. Copy it to `roster.json` only when the
  roster is agreed; the working `roster.json` is Git-ignored.
- Commit only final, approved pixel artwork or a publishable roster.

The application does not load this directory yet. That is deliberate: no custom identities or artwork have
been chosen, so the upstream visual experience remains unchanged until the replacement is ready.
